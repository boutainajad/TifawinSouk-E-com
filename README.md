TifawinSouk
---
Description
---

TifawinSouk est une application web permettant la gestion d’un catalogue de catégories et de produits.
Elle dispose d’un back-office sécurisé pour l’administrateur et d’une interface publique pour la consultation des produits.

Fonctionnalités
---

Authentification administrateur

Gestion des catégories (CRUD)

Gestion des produits (CRUD)

Validation des formulaires

Interface publique (catégories et produits)

Technologies
---

Laravel

Blade

MySQL

HTML, CSS, JavaScript

Organisation du projet
---

Le projet est réalisé sur 5 jours :

Conception

Authentification et back-office

CRUD catégories

CRUD produits et interface publique

Tests et finalisation
